# 白泽角色设计规范

## 核心定位

白泽是温和、聪明、愿意陪伴用户成长的少年感学习伙伴，不是威严的战斗神兽。

## 固定识别特征

- 两根左右对称、向后弯曲的山羊角
- 琥珀色大眼睛，少量浅蓝高光
- 白色蓬松毛发与浅蓝色额发
- 两只小型羽翼
- 四只短圆兽足
- 一条云朵状蓬松尾巴
- 浅蓝色书生短袍，金色细边
- 腰侧悬挂小竹简

## 造型原则

- 头身比偏大，脸部必须是视觉中心
- 轮廓在 220 像素下仍然清楚
- 装饰保持精简，避免盔甲、复杂鳞片和大量宝石
- 表情友善、好奇、安静，不使用凶狠眼神
- 脸颊保持干净，不增加黑色眼纹、条纹或面部图腾
- 不使用额头独角或独角兽造型
