# 白泽（Project Baize） v5\.0 方案优化版

本次优化**完全保留原方案 “灵力世界观 \+ 开源底座 \+ 商业 SaaS” 的核心战略**，针对原方案的「成本模型鲁棒性不足、教育留存抓手单薄、开源商业边界模糊、合规风险有隐患」四大核心问题做定向加固，不推翻原有框架，只做闭环补全与落地提效。

## 一、商业化与财务模型优化：加固成本护城河，提升付费天花板

### 1\. 灵力 \- 成本映射精细化，解决定价与成本错配

将原方案 3 档粗糙的消耗分级，升级为**6 级语义复杂度分级**，与端侧二级过滤链路一一对应，让每 1 点灵力的成本锚定误差控制在 ±10% 以内：

|复杂度等级|灵力消耗|后端处理链路|适用场景|
|---|---|---|---|
|L0 本地级|0|纯本地规则引擎 \+ 离线小模型|基础闲聊、状态交互、本地题库|
|L1 轻量级|\-1|端侧 VLM 初筛 \+ 轻量文本 LLM|普通知识识别、简单概念解释|
|L2 标准级|\-2|云端轻量 VLM 单次解析|普通习题讲解、知识点梳理|
|L3 深度级|\-3|云端标准 VLM 完整解析|复杂题目、截图深度分析|
|L4 全链路级|\-5|VLM 解析 \+ 教育 RAG 检索 \+ 长文本生成|体系化知识点拆解、错题深度分析|
|L5 实时级|\-2 / 分钟|流式 TTS \+ 多轮上下文维持|实时讲解、连续对话陪伴|

同时建立**动态校准机制**：每周根据真实 API 成本数据微调灵力系数，确保所有付费档位毛利始终≥60%。

### 2\. 白嫖机制封顶控本，避免算力刷取

原方案 “答题无限换灵力” 存在成本击穿风险，优化为双上限管控：

- 基础用户每日通过试炼最多获取 200 灵力，订阅用户每日上限翻倍，超出后答题仅增加羁绊经验，不增加灵力；

- 单题灵力奖励与正确率挂钩：正确率≥80% 单题 \+ 5 灵力，正确率＜50% 单题仅 \+ 2 灵力，引导用户认真答题而非刷量，同时提升教育价值。

### 3\. 付费体系补全，不破坏 “羁绊不可购买” 原则

- **新增纯装饰性付费**：推出「山海绘卷」系列皮肤、专属动作、界面特效，定价 9\.9\-19\.9 元 / 款，100% 毛利，只改变外观不增加灵力与功能，既满足情感付费需求，又不打破数值公平性。

- **订阅制优化**：新增连续包月优惠价（契约版 15 元 / 月、神兽版 29 元 / 月），降低首次订阅门槛；订阅用户额外享有 “离线修炼双倍灵力” 权益，强化付费感知。

- **BYOK 模式风险收口**：99 元创世版从 “无限灵力” 调整为「基础功能无限，L3 及以上深度解析每日限额 100 次」，防止用户用自有 API Key 跑批量任务拖垮服务带宽；新增 199 元 / 月团队版，支持 3 台设备，面向小型教育工作室与学习小组。

- **裂变拉新机制**：邀请好友注册双方各得 50 灵力，好友首次完成订阅，邀请者得 1 个月神兽版权益，用虚拟权益替代现金补贴，拉新成本趋近于 0。

## 二、产品体验与留存优化：强化情感连接，解决答题枯燥痛点

### 1\. 知识试炼场景化，从 “凭空答题” 到 “随屏学习”

把孤立的题库答题和产品核心的「屏幕感知」能力绑定，彻底提升试炼的实用性与代入感：

- **随屏试炼**：端侧模型识别到用户正在浏览网课、习题、课本内容时，自动提取当前页面知识点生成 3\-5 道配套题目，答对奖励灵力，让答题和用户真实学习行为强关联，而非凭空出题。

- **试炼形式多元化**：新增填空、判断、错题复盘、知识点背诵等模式，不局限于选择题，适配数理化、文史等不同学科特性。

- **错题本机制**：端侧自动收录用户答错的题目，定期生成 “复盘试炼”，答对可获双倍灵力，既强化教育效果，又创造复访理由。

### 2\. 羁绊系统情感化升级，不止是数值等级

原方案的羁绊仅解锁形态与功能，情感厚度不足，优化为「等级 \+ 记忆 \+ 剧情」三位一体：

- **本地专属记忆库**：端侧存储用户的学习习惯、易错知识点、常聊话题，羁绊等级越高，白泽的个性化程度越强 —— 比如 Lv3 会主动提醒 “你上周做错的物理题，要不要再练一遍”，所有数据 100% 本地存储，不涉及隐私上传。

- **羁绊剧情节点**：每个大等级解锁 1 段 10\-15 秒的序列帧小剧情（如 Lv3 解锁「共赴书山」、Lv5 解锁「守夜明灯」），用轻量内容替代纯数值升级，强化成长仪式感，控制美术资源成本。

### 3\. 状态机补充正向反馈，降低流失率

- **离线修炼机制**：客户端关闭后，按离线时长累计灵力（最多 12 小时，上限 30 点），次日上线领取，贴合 “沉睡吸收灵气” 的世界观，显著提升次日留存。

- **沉睡状态优化**：原方案沉睡状态完全拒绝交互，优化为「允许本地小模型纯文本闲聊，不消耗灵力，仅拒绝高成本 VLM 调用」，保留基础陪伴感，避免用户因灵力耗尽直接卸载。

- **随机灵机事件**：灵力充盈状态下，随机触发知识点彩蛋、学习方法小贴士，免费输出干货，提升用户好感与产品价值感知。

## 三、技术架构优化：提升成本控制精度，降低工程风险

### 1\. 端侧二级过滤体系，筑牢成本防线

这是整个灵力财务模型成立的核心工程保障，将原方案的单一端侧初筛升级为二级过滤，目标是把 85% 以上的请求拦截在本地：

1. **第一级：视觉场景快速分类**
用 YOLOv8\-nano 毫秒级识别屏幕场景（学习 / 游戏 / 聊天 / 办公 / 其他），非学习场景直接拦截高成本 VLM 调用，游戏场景自动降级为纯文本陪伴模式，从源头减少无效云端请求。

2. **第二级：语义复杂度分级**
用 Qwen2\-VL\-2B 对学习内容做复杂度评分，输出 L0\-L5 的等级标签，匹配对应的处理链路与灵力消耗，避免 “简单问题用大模型” 的成本浪费。

3. **本地缓存池**
对常见知识点、高频识别的教材页面、习题答案做本地缓存，重复请求直接返回结果，不消耗云端算力；缓存有效期 7 天，自动更新。

### 2\. 核心体验优化

- **本地 TTS 兜底方案**：集成端侧轻量 TTS 模型（ONNX 格式精简版），灵力不足或网络不佳时自动切换，灵力消耗仅为云端 TTS 的 1/3，世界观包装为 “灵力不足时的轻声模式”，既降本又不破坏体验。

- **资源动态加载**：不同羁绊等级的序列帧、语音包按需加载，不一次性导入全部素材，降低内存占用，适配低配 Windows 设备。

### 3\. 反作弊与兼容性升级

- 维护**云端动态游戏进程库**，自动识别新增的强反作弊游戏并实时降级，无需用户更新客户端；

- 新增手动切换开关：用户可一键切换「纯本地陪伴模式」「学习模式」「深度解析模式」，给用户完全控制权，避免误触发游戏反作弊导致账号风险。

## 四、合规与内容风险优化：从根源规避隐患

### 1\. 题库版权风险缓释

- **冷启动优先使用公版资源**：首批题库优先采用教育部公开的历年中高考真题、国家中小学智慧教育平台公开习题、CC0 协议开源题库，确保初始内容无版权风险。

- **UGC 审核机制**：用户上传题目可获得灵力奖励，所有内容先经端侧敏感词过滤，再人工抽检标注来源，逐步搭建自有原创题库，降低侵权依赖。

### 2\. 隐私合规加固

- **全维度敏感信息脱敏**：在原有人脸、聊天框脱敏基础上，新增端侧 OCR 识别身份证号、银行卡号、手机号、密码框，自动打码拦截，确保上传云端的图片无任何敏感信息。

- **零知识证明升级**：家长端仅展示学习时长、试炼完成率、学科薄弱项等统计数据，所有原始截图、对话内容 100% 保留在用户本地，云端不存储任何用户屏幕数据。

### 3\. IP 侵权风险规避

内置**本地关键词映射引擎**：用户输入的版权 IP 名称在本地自动替换为泛化代称，云端接收不到具体 IP 名称；台词库全部使用泛化表述，从根源规避游戏、影视 IP 的侵权风险。

## 五、开源策略与落地节奏优化：平衡社区价值与商业壁垒

### 1\. 双授权模式，解决开源与商业的冲突

原方案全量 AGPL 开源存在被直接复刻商业化的风险，优化为「底座开源 \+ 商业模块闭源」的双授权模式：

- 核心技术底座（DXGI 截图引擎、端侧推理框架、基础 UI、本地规则引擎）维持 AGPL v3 开源，面向极客社区，吸引开发者贡献优化；

- 商业核心模块（灵力系统、羁绊系统、支付体系、教育 RAG 知识库）闭源，作为 SaaS 增值服务提供。第三方 Fork 仅能获得基础功能，无法直接复刻完整商业化产品，既保留开源社区活力，又守住商业壁垒。

- 配套设立开发者激励计划：社区贡献的优质模型优化、功能插件，可兑换创世版订阅或现金奖励，反哺产品迭代。

### 2\. 90 天 Roadmap 迭代，验证节点前置

将原方案的里程碑拆分细化，把核心生死指标的验证提前 30 天，降低试错成本：

- **Day 1\-15 底座验证期**：跑通 “截图 \- 端侧二级过滤 \- 云端 VLM \- 流式 TTS \- 基础 UI” 最小闭环，输出精准的成本 \- 灵力映射表，完成财务模型校准。

- **Day 16\-45 商业化验证期**：实装灵力系统 \+ 随屏试炼基础版 \+ 礼物支付系统，开启 100 人种子内测，核心验证**付费转化率**和**单用户日均算力成本**两个生死指标。

- **Day 46\-90 留存与正式期**：实装羁绊 Lv1\-Lv3 \+ 离线修炼 \+ 错题本，完成 ICP 备案与软著申请，开启 500 人公测，同步启动开源社区运营。

### 3\. 第一周行动清单补充

在原有 6 项任务基础上，新增 3 项高优先级动作：

1. 完成 1000 道公版版权题库整理（原 500 道翻倍），覆盖初中数理化核心知识点；

2. 搭建实时成本监控看板，统计单用户 API 成本、灵力消耗比，作为后续调参依据；

3. 输出双授权协议草案，明确开源与闭源的模块边界。

## 六、新增：风险熔断与运营兜底机制

### 1\. 成本自动熔断

- 当日云端 API 总消耗达到日预算 80% 时，自动触发「灵气潮汐」全服活动：答题奖励翻倍，引导用户转向零成本试炼，自动压低云端调用量；

- 单用户当日高成本调用达到阈值时，自动提示上限，防止单用户异常消耗击穿成本。

### 2\. 运营内容兜底

- 预设每周学科主题活动，对应学科试炼奖励翻倍，持续激活用户；

- 节日节点推出限定灵物、限定外观，做短期付费冲刺。
